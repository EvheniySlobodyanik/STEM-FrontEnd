## 🎮 Призначення та легенда проєкту

Централізована фронтенд-панель оперативного диспетчерського контролю для GameOps-інженерів та адміністраторів розподіленої серверної інфраструктури.

### Проблема:

У географічно розподіленій інфраструктурі ігрових сервісів падіння вузла або раптовий стрибок навантаження CPU/RAM погіршує досвід тисяч активних гравців одночасно (лаговий тикрейт, розрив з'єднань, черги). Читання сирих SSH/консольних журналів для десятків серверів вимагає забагато часу.

### Рішення:

React-додаток **GameOps Core** агрегує телеметрію в реальному часі з розподілених регіонів (`EU-Central`, `US-East`, `Asia-Pacific`, `SA-East`), візуалізує динаміку навантаження (CPU, мережевий пінґ, онлайн гравців, стабільність tickrate) за допомогою `Recharts`, відображає кінцевий автомат станів вузлів (`Online`, `Degraded`, `Maintenance`, `Offline`) та надає інструменти оперативного диспетчерського керування в один клік (Restart, Maintenance Toggle, Power Off/On).

### Головна цінність:

Суттєве скорочення середнього часу відновлення працездатності (**MTTR** — _Mean Time to Recovery_) під час інцидентів та доступність зрозумілого UI.

## 🛠 Технологічний стек

- **Бібліотека UI:** [React 19](https://react.dev/) (функціональні компоненти, хуки `useState`, `useEffect`, `useMemo`)
- **Збирач:** [Vite 8](https://vitejs.dev/) (швидкий HMR, модульне складання ES-модулів)
- **Стилізація:** [Tailwind CSS v4](https://tailwindcss.com/) (темна кібер-палітра, неонові стани, адаптивна CSS Grid / Flexbox сітка)
- **Візуалізація телеметрії:** [Recharts](https://recharts.org/) (інтерактивні AreaChart з градієнтними заливками та підказками)
- **Іконки:** [Lucide React](https://lucide.dev/) (легковагові векторні SVG-іконки)

## 📋 Модель станів серверного вузла (State Machine)

Кожна серверна нода функціонує згідно з детермінованим автоматом станів:

1. **Online (В мережі):** Штатний режим. Усі системні процеси стабільні, відхилень тикрейту немає. (Колір: Emerald / Зелений).
2. **Degraded (Деградація):** Фіксація підвищеного навантаження (CPU > 85%, пінг > 150ms або просідання tickrate). (Колір: Amber / Жовтий, що пульсує).
3. **Maintenance (Обслуговування):** Ноду виведено з балансувальника для регламентних робіт / патчу. Прийом нових гравців заблоковано. (Колір: Blue / Синій).
4. **Offline (Відключено):** Аварійне падіння або примусове вимкнення живлення. (Колір: Rose / Червоний).

## 🚀 Встановлення та запуск

### 1. Клонування репозиторію:

```bash
git clone https://github.com/EvheniySlobodyanik/STEM-FrontEnd.git
cd STEM-FrontEnd
```

### 2. Встановлення залежностей:

```bash
npm install
```

### 3. Запуск локального сервера розробки:

```bash
npm run dev
```

Після запуску відкрийте у браузері: `http://localhost:5173/`

### 4. Збірка для продакшену:

```bash
npm run build
```

Зібрані оптимізовані статичні файли генеруються у папці `dist/`.
